# 智慧树助手一体版

[下载最新版安装包](https://github.com/xudahai76-dotcom/-/raw/refs/heads/main/zhihuishu-assistant-v2.1.2.zip) · 当前版本 **2.1.2**

一个 Chrome 扩展，提供智慧树课程原速连续播放和 DeepSeek 随堂题辅助。视频完整播放结束后等待 **5 秒**再切下一节，跨章继续播放；**章节测试和考试自行完成**。无需另外安装 Tampermonkey 脚本或辅助扩展。

## 使用前准备

- 使用 **桌面版 Google Chrome 125 或更新版本**，并先登录智慧树。主要使用环境为 Windows + Chrome，其他浏览器未验证。
- 自动答题目前**只支持 DeepSeek 官方 API**，固定连接 `api.deepseek.com`。不能使用 ChatGPT、其他服务商的密钥或中转地址。
- 自动答题需要在 [DeepSeek 开放平台](https://platform.deepseek.com/) 创建 API Key，账户有可用额度，模型名称默认保持 `deepseek-flash`。随堂题文字和选项会发送给 DeepSeek，按其规则计费，答案可能有误。模型与接口说明见 [DeepSeek 官方文档](https://api-docs.deepseek.com/)。
- 只想连续播放，可关闭“自动处理随堂弹题”，无需填写 API Key。遇到随堂题请手动完成，必要时再次点击“开始”。

## 安装：只需一次

1. 点击上方链接下载扩展安装 ZIP，解压到准备长期保留的位置。
2. 在 Chrome 地址栏输入 `chrome://extensions`，打开右上角“开发者模式”。
3. 点击“加载已解压的扩展程序”，选择解压后的 **zhihuishu-unified** 文件夹。所选文件夹内必须直接看到 `manifest.json`；若下载的是仓库源码，则选择含该文件的源码根目录。
4. 如安装过旧版智慧树脚本或辅助扩展，请先停用，避免重复运行。打开课程视频页并刷新，等待“一体版 2.1.2”面板出现。

**安装后不要移动或删除这个文件夹**，Chrome 会从中加载扩展。可在浏览器右上角“扩展程序”菜单中固定本扩展，方便找到图标。

## 配置并开始

1. 点击课程面板“配置密钥”，或右击扩展图标选择“选项”。填写 DeepSeek API Key、可用模型名称后点击“保存设置”。只看视频则取消勾选“自动处理随堂弹题”后保存。
2. 返回课程页。共享课还需点击本扩展图标，确认出现 **ON**；智慧课程无需这一步。
3. 点击面板“开始”。需要停止时点击“暂停”。保存新设置会暂停任务，返回课程页再次点击“开始”即可使用新设置。

共享课通常使用 `studyvideoh5.zhihuishu.com/stuStudy`，智慧课程使用 `wisdom-mooc.zhihuishu.com/study/index`。共享课的 ON 只对当前启用的标签页有效；刷新、离开页面或调试连接断开后，需再次点击图标开启。Chrome 显示调试提示是共享课点击功能所用权限的提示。

密钥保存在本扩展的本地存储中，不同步到云端，仅用于请求 DeepSeek。设置页不会回显密钥；留空保存会保留原密钥，需要删除时点击“清除已保存的密钥”。旧脚本中的密钥不会自动导入。

## 常见问题

| 现象 | 处理方法 |
| --- | --- |
| 没有面板或一直等待启动 | 确认扩展已启用且进入具体课程视频页，等待加载完成；仍失败则点击“重试启动”或刷新。 |
| “配置密钥”打不开 | 右击扩展图标 →“选项”。若曾出现“本地状态保存失败”，配置后先刷新课程页再开始。 |
| 共享课不答题或不切课 | 检查图标是否显示 ON；刷新后需重新启用。 |
| API Key、余额或模型错误 | 检查官方 DeepSeek 密钥、账户额度及模型名称；其他平台密钥不可用。 |
| 卡在弹窗、验证或某一节 | 按网页提示手动处理；无法切课时手动选中下一节再开始。仍异常可用“复制诊断”反馈。 |

## 更新与适配说明

更新时先暂停，将新版文件覆盖到原扩展目录，避免多套一层文件夹。在 `chrome://extensions` 点击该扩展的重新加载按钮，再刷新课程页；共享课重新开启 ON。保留原目录和扩展，已保存设置与密钥可继续使用。

本扩展申请本地存储、剪贴板和调试权限；调试权限用于手动启用的共享课标签页点击，复制按钮用于写入剪贴板。登录、安全验证及未适配题型需要人工处理，学习完成状态以网站记录为准。

已做离线功能检查，不保证所有课程及网站改版都适用。旧版 `studyh5.zhihuishu.com/videoStudy` 保留兼容逻辑，尚未全面验证；章节作业和考试页不运行本扩展。
